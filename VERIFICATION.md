# Проверки

Пройдены 12 тестов, линтер и форматирование. Через Docker API проверен полный цикл
эксперимента: назначения, фактические показы, метрики, запрет преждевременного
анализа и финальный отчёт. Тестами дополнительно проверены протокол до начала
эксперимента, блокировка выводов при регистрации задним числом, расчёт CUPED
по сохранённому пилоту, неизменяемость ковариаты, конкурентная дедупликация
и поведение интервалов при нулевой дисперсии.

Симуляция: 400 повторов на сценарий, 600 пользователей в группе, seed=42.
При нулевом эффекте частота ложных выводов составила 2% для фиксированного анализа
(95% интервал 0,87–3,90%) и 1% для трёх заранее заданных проверок.
При изменении конверсии с 15% до 25% частота обнаружения составила 99% и 97,25%.
Числа относятся только к заданной синтетической модели данных.
