# Зафиксированные null-симуляции

Seed381009, 400 независимых повторов каждого режима. В исходной популяции эффект равен нулю для обеих метрик. Исследуется частота хотя бы одного significant вывода с действующим SRM gate; fixed и planned считаются отдельно. Planned — три заранее заданных look200/400/600, alpha0.05/3; недоступные looks пропускаются без перераспределения alpha. Counts на раннем look задаются пропорционально числу зрелых показов; это модель наблюдения, а не нагрузочный HTTP-тест.

Условия:

- independent_gamma: Bernoulli0.15 × Gamma(2,20) + 0.8 pre; pre Gamma(2,10), независимый pilot1000rows с theta около0.8.
- heavy_tail_lognormal: денежный шум LogNormal(mu2,sigma2.2), прежние conversion/pre; конечная, но тяжёлая дисперсия.
- allocation_75_25: 900/300 зрелых показов вместо600/600; SRM отвергает все повторы. Нулевая частота не означает приемлемый дисбаланс.
- dropout_mcar_25pct: независимое удаление25% показов каждой группы.
- dropout_outcome_selected_balanced: в A остаются360 наименьших денежных исходов, в B360 наибольших; время остальных показов сохраняется. Это намеренное нарушение предпосылок. SRM не видит его, оба режима дают400/400 ложных выводов относительно исходной популяции. Оно не считается корректным A/B-экспериментом.
- wrong_independent_pilot: пилот имеет связь-0.8 вместо+0.8, theta заморожен до анализа; одинаковый общий сдвиг делает pilot revenue неотрицательным и не меняет covariance. Ошибочный независимый коэффициент не обязан увеличивать type I error: он ухудшает variance reduction. Настройка theta по эксперименту не выполнялась.

Полные counts/denominators, unavailable looks, seed/protocol/script SHA256: [JSON](simulation-results.json). Интервалы — точные биномиальные Clopper–Pearson через [SciPy proportion_ci](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats._result_classes.BinomTestResult.proportion_ci.html). Это неопределённость Monte Carlo частоты, а не интервал эффекта одного эксперимента. 400повторов и указанные условия не доказывают универсальный контроль ошибки или production SLA.

Время финальной симуляции 7.544s; NumPy2.5.3, native macOS/aarch64. Синтетические данные, production stats.py неизменён. Выбор режима/параметров зафиксирован до результатов; первая техническая версия pilot имела отрицательные суммы и была исправлена общим сдвигом для соответствия API, без смены covariance/порогов.
